# Liste des 480 mots

Banque proposée dans la PR #4 : 80 mots par catégorie. Les variantes sont des réponses acceptées pour le même mot, pas des mots supplémentaires.

Le classement vise la familiarité supposée auprès d’un public francophone : **facile** pour les références grand public, **intermédiaire** pour les amateurs du domaine, **difficile** pour les références spécialisées. Il reste subjectif et ajustable. Les sous-catégories sont les filtres du jeu ; certaines regroupent plusieurs genres.
